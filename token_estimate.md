# Token Estimate & Cost Analysis

## Model Pricing (Anthropic claude-sonnet-4-6)
- **Input tokens**: $3.00 per million tokens
- **Output tokens**: $15.00 per million tokens

---

## Call Breakdown for 250 Requests

### 1. Vision Calls (Image Amount Extraction)
| Metric | Value |
|--------|-------|
| Images to process | 16 |
| Calls | 1 (single multi-image call with all 16 images) |
| Images per call | 16 |
| Input tokens per image | ~1,200 (1024px base64 + prompt) |
| Output tokens per image | ~50 (JSON response) |
| **Total input tokens** | 16 × 1,200 = **19,200** |
| **Total output tokens** | 16 × 50 = **800** |
| **Vision cost** | (19,200 × $3 + 800 × $15) / 1M = **$0.0696** |

**Note**: Images are preprocessed to max 1024px to minimize tokens. Cached after first run.

---

### 2. Message Interpretation Calls
| Metric | Value |
|--------|-------|
| Messages with request_id | 128 |
| Users with request messages | ~80 (some users have multiple) |
| Batched calls | 5 (15-25 messages per call, grouped by user) |
| Messages per call | ~25 |
| System prompt tokens | ~300 |
| User prompt per message | ~150 |
| Output tokens per message | ~80 |
| **Input tokens per call** | 300 + 25 × 150 = **4,050** |
| **Output tokens per call** | 25 × 80 = **2,000** |
| **Total input tokens** | 5 × 4,050 = **20,250** |
| **Total output tokens** | 5 × 2,000 = **10,000** |
| **Messages cost** | (20,250 × $3 + 10,000 × $15) / 1M = **$0.2108** |

---

### 3. Decision Explanation Calls
| Metric | Value |
|--------|-------|
| Requests | 250 |
| Batched calls | 10 (25 requests per call) |
| Requests per call | 25 |
| System prompt tokens | ~400 |
| User prompt per request | ~200 (context + facts) |
| Output tokens per request | ~120 (1-2 sentences) |
| **Input tokens per call** | 400 + 25 × 200 = **5,400** |
| **Output tokens per call** | 25 × 120 = **3,000** |
| **Total input tokens** | 10 × 5,400 = **54,000** |
| **Total output tokens** | 10 × 3,000 = **30,000** |
| **Explanations cost** | (54,000 × $3 + 30,000 × $15) / 1M = **$0.6120** |

## Token Budget Safety Margins

| Scenario | Total Cost | Margin |
|----------|------------|--------|
| Baseline estimate | $0.89 | — |
| +50% token usage (larger contexts) | $1.34 | 2.5× buffer |
| +100% token usage | $1.78 | 2× buffer |
| All calls unbatched (worst case) | ~$3.50 | 4× buffer |

**Conclusion**: Well within any reasonable budget. Even at 4× estimate, total < $4.

## Caching Impact (Repeated Runs)

| Run | Vision | Messages | Explanations | Total Cost |
|-----|--------|----------|--------------|------------|
| First run | 19,200 | 20,250 | 54,000 | $0.89 |
| Subsequent runs | 0 (cached) | 0 (cached) | ~10% cache miss | ~$0.10 |

**Caching strategy**:
- Vision: 16 images → cached to `cache/image_extractions.json` (never re-run)
- Messages: Per user-request batch → cached to `cache/message_interpretations.json`
- Explanations: Per request_id → cached to `cache/explanation_cache.json`

## Cost Optimization Notes

1. **Vision batching**: Single call for all 16 images saves 15 call overheads
2. **Message batching**: Grouped by user (not request) reduces redundant context
3. **Explanation batching**: 25 requests/call amortizes system prompt cost
4. **Temperature=0**: Deterministic, no sampling overhead
5. **Caching**: Subsequent runs cost ~$0.10 (99% reduction)
6. **Image preprocessing**: 1024px max reduces vision tokens by ~60% vs full-res

## Edge Case Token Estimates

| Edge Case | Additional Tokens | Additional Cost |
|-----------|-------------------|-----------------|
| Retry failed Vision (1 image) | +1,250 | $0.004 |
| Retry failed Explanations (1 batch) | +8,400 | $0.06 |
| All messages unbatched (128 calls) | +300,000 | $4.80 |
| All explanations unbatched (250 calls) | +400,000 | $6.30 |

**Recommendation**: Batching is critical. Unbatched worst-case still < $12 but avoided by design.
